## Setup

On Windows, develop inside WSL (Ubuntu). Install the Linux dependencies, Rust, the Solana CLI and Anchor by following the official guide: https://solana.com/docs/intro/installation/dependencies

Versions used so far: rustc 1.90.0, solana-cli 4.1.2, anchor-cli 1.2.2.

1. Point the Solana CLI at devnet and create a dev wallet:
   `solana config set -ud` then `solana-keygen new`
2. Fund the wallet with devnet SOL (`solana airdrop`, or https://faucet.solana.com).
3. Build and deploy: `anchor build` then `anchor program deploy`
